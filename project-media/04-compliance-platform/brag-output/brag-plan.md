# Brag Plan: Multi-Tenant AI Compliance Platform (project 04)

Tone: cinematic (user request). Trailer pacing: short declarative lines, slow camera moves, depth, light beams, grain. Silent, 1920x1080, 12 s, loops from and to the empty stage.

Page colour: deep plum #1b1230 (new for this project); light: lavender #b9a4ff, from the purple in the client's architecture diagram. The video stage is built from the page colour.

1. Hook (0-2.6s): "Many tenants." / "One platform." / "Their data never mixes." Blur-to-sharp, scale settle, then the camera pushes through.
2. The vaults (2.6-5.4s): three tenant vaults rise out of depth. A bilingual question (English and Arabic) sends a beam into Organisation A only; B and C stay locked. "Scope is enforced at retrieval, so tenant data never mixes."
3. The retrieval run (5.4-8.6s): the camera tracks along the five stages: ACL filter in the query, Dense top-40 + BM25 top-40, Reciprocal rank fusion, Cross-encoder rerank to top-8, Answer with citations. Each lights as it passes centre.
4. The answer (8.6-12s): "16 consultant personas. Every answer cited." Answer card with citations, English and Arabic, evaluated with RAGAS + Arize Phoenix. Hold, fade.

Illustrative: the question wording and tenant names (Organisation A, B, C). Stage names and claims come from the client's diagram and description.
