# Hyperframes Composition Brief: Enterprise voice AI agent

## Objective
A 12 s silent looping portrait clip for the Selected work preview card (row 01) of Haris's portfolio.

## Output
- Composition directory: brag-output/composition/
- Rendered video: brag-output/brag.mp4, then web encodes in public/landing/selected/media/01-voice-agent/
- Format: vertical 4:5, 1080x1350, 60 fps
- Duration: 12 s (user override; looping card)

## Source Material
- Retell conversation-flow screenshots and n8n outage-check workflow (sanitised copies in ../src: brand name and client API URL blurred, watermark cropped)
- Verbatim: department names from the global node transitions (Technical support, Billing, Sales, Renewals, Retention, Complaints, Customer service)

## Creative Direction
- Tone: cinematic, restrained; dark warm stage, amber accent #f2b84b (the broadband project colour on the site)
- Fonts: Bodoni Moda (display), Manrope (captions), JetBrains Mono (labels), all local woff2
- Hook: a live call waveform, "Answered in zero seconds."
- Outro: department chips, "Every call, routed.", fade to black for the loop

## Storyboard
See brag-plan.md (5 scenes: hook 2.3 s, flow 3.1 s, triage 2.9 s, outage check 2.2 s, routed 1.5 s).

## Audio
Intentional silence (--no-music --no-sfx; plays muted in a card).
