# Brag plan: White-label estimation product across seven tenants (Selected work 03)
Source: PDF project 08. Client names withheld; the pricing model is proprietary and never shown.
1. What: a resold AI lead-capture and estimation tool: a photo goes in through a web form, a usability gate checks it, a vision model plus a fixed deterministic rubric prices it, a price range goes back by SMS and email, and full quotes write line items into the client's field-service CRM.
2. Who: trade businesses (seven paying tenants) and their customers.
3. Strongest claim: one core safely cloned across seven live tenants, because the model reads the photo but does not invent the price.
4. Key visual: photo -> usability gate -> vision + fixed rubric -> price range by SMS + email / quote lines into the CRM -> 7 tenants.
5. Verbatim: "Ask for a better photo", "Vision model + fixed rubric", "Price range by SMS + email", "Quote lines into the CRM", "7 live tenants".
6. Tone: cinematic product demo. Edit style: punchy zoom cuts on cards, then a pull-back grid reveal. Magenta #ff7ad9 on #170d1c.
7. 1080x1350, 12 s, silent loop.
## Storyboard
1. 0.0-2.8 Hook: a job photo is submitted; the usability gate bounces a blurry one ("Ask for a better photo"), the retake passes.
2. 2.8-5.8 Vision: a scan line sweeps the photo; "The model reads the photo. The rubric sets the price."
3. 5.8-8.8 Out: an SMS bubble and an email arrive with a price range (amounts withheld), quote lines drop into the CRM.
4. 8.8-12 Pull back: the whole core shrinks into one tile of seven; all seven light up; "One core, seven businesses." Fade.
